# Workspace instructions

## Mandatory instructions before source changes

- Before every task that edits source code, locate and read the applicable `AGENTS.md` files for the target directory before making any source-code changes. Re-read them for each task; reading them in an earlier task or turn does not count.
- If the target directory or applicable instructions change during a task, read the newly applicable `AGENTS.md` files before editing there.
- Do not modify source code until these instructions have been read. If an applicable `AGENTS.md` cannot be accessed, stop before editing source code and report the issue.
