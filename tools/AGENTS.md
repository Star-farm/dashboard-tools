# Desktop interaction and software testing

For desktop GUI interaction and testing, prefer the installed agent-desktop CLI at `tools/agent-desktop/node_modules/.bin/agent-desktop.cmd` when appropriate and available. Before first use in a session, run `skills get desktop` and `skills get platform` with that CLI and follow their guidance. Observe the UI, act, and verify the result; use other tools when required by the environment or task.

# Website development

For website development, consult relevant role instructions in `tools/agency-agents` when useful, such as engineering, design, and testing roles. Apply them within the current task and higher-priority instructions; use delegation only when authorized by the current session.
